## Đã làm

### Tuần 3-4: Dựng 4 VM (Ubuntu Server 22.04 LTS)

- Dùng VMware Workstation, cấu hình 2 network adapter mỗi VM:
  - `ens33` host-only: IP tĩnh subnet `192.168.243.0/24`
  - `ens37` NAT: để lấy internet tạm khi cần cài đặt
- IP tĩnh qua Netplan (mẫu: `infra/networking/netplan-example.yaml`):
  | Node | Hostname | IP |
  |---|---|---|
  | Control-plane | k3s-master | 192.168.243.10 |
  | Worker 1 | k3s-worker1 | 192.168.243.11 |
  | Worker 2 | k3s-worker2 | 192.168.243.12 |
  | Worker 3 | k3s-worker3 | 192.168.243.13 |
- Specs: master 3GB RAM 2vCPU, worker 2GB RAM 2vCPU
- Tắt swap, đồng bộ thời gian chrony trên tất cả node
- Tạo VM master trước, clone ra 3 worker, đổi hostname/IP và tạo lại machine-id cho mỗi bản clone

### Tuần 5-6: Cài k3s cluster

- Cài k3s server trên master (v1.36.5+k3s1) với `--node-ip` và `--flannel-iface ens33`
- Join 3 worker vào cluster bằng node-token (cũng có `--node-ip`, `--flannel-iface ens33`)
- Verify: `kubectl get nodes -o wide` → 4 node Ready, INTERNAL-IP 192.168.243.10–13
- metrics-server có sẵn trong k3s, kiểm tra bằng `kubectl top nodes`

### Tuần 7-8 (trước schedule): Cài OpenFaaS + KEDA

- Cài Helm v3, rồi OpenFaaS CE bằng Helm chart:
  ```bash
  helm repo add openfaas https://openfaas.github.io/faas-netes/
  kubectl create namespace openfaas && kubectl create namespace openfaas-fn
  helm install openfaas openfaas/openfaas --namespace openfaas \
    --set functionNamespace=openfaas-fn --set generateBasicAuth=true
  ```
  - Gateway NodePort: `192.168.243.10:31112`, kiểm tra bằng function `figlet`
  - Đặt OPENFAAS_URL trong `~/.bashrc`
- Cài KEDA bằng Helm:
  ```bash
  helm repo add kedacore https://kedacore.github.io/charts
  helm install keda kedacore/keda --namespace keda --create-namespace
  ```
  - Verify: `kubectl get pods -n keda`

### Tuần 10 (trước schedule): Prometheus, Grafana, k6, Tailscale

- Prometheus: đi kèm với OpenFaaS, namespace `openfaas`
  - Địa chỉ trong cluster: `http://prometheus.openfaas:9090`
- Grafana: Helm chart `grafana/grafana`, namespace `monitoring`, NodePort `31782`
- k6 v2.3.0: tải file nhị phân từ GitHub releases (cài qua apt lỗi do khóa ký của repo đã đổi)
- Tailscale chỉ cài trên master, đăng nhập tài khoản cá nhân:
  ```bash
  curl -fsSL https://tailscale.com/install.sh | sh
  sudo tailscale up
  ```
  - Master Tailscale IP: `100.88.160.40`
  - Tạo user `tranduc` và `huynhqui` có quyền kubectl

## Vấn đề gặp phải & cách xử lý

| Vấn đề | Nguyên nhân | Cách xử lý |
|---|---|---|
| Phải gõ lệnh bật internet sau mỗi lần reboot | ens33 có `gateway4`, ens37 không tự nhận IP | Sửa netplan: bỏ gateway ở ens33, ens37 `dhcp4: yes` |
| Worker join xong nhưng không hiện trên master | Worker chưa có internet để tải k3s agent | Bật internet qua ens37 rồi chạy lại lệnh join |
| Pull image lỗi `connection reset`, gateway CrashLoopBackOff mãi | 3 worker clone chung machine-id → DHCP cấp trùng IP; k3s đăng ký node bằng IP NAT | Tạo lại machine-id, cài lại k3s với `--node-ip` + `--flannel-iface ens33`; sau đó OpenFaaS lên trong ~2 phút |
| Lỗi chart cũ (`--version 14.2.33`) không pull được image | Chart cũ trỏ tới image không còn tồn tại | Dùng chart mới nhất |
| Tailscale vào nhầm mạng chung của trường | Đăng nhập bằng email trường nên bị gộp vào tailnet của trường | `tailscale logout`, đăng nhập lại bằng tài khoản cá nhân; đổi mật khẩu user ubuntu |
